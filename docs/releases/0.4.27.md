# Fork 0.4.27 - Upstream 0.4.22 merged

Use **Mein Fork** and **Aktualisieren und spielen** in the existing launcher.
Exit both games normally before updating. All players need this package.

## New

This release merges the upstream `release-0.4.22` branch (silver2127) into the
fork, on top of the one-click resync from 0.4.26. From upstream 0.4.16 to
0.4.22:

- Joining no longer needs the host to open a port: the lobbies punch through
  their routers with the master server's help, with a direct dial first.
- A Windows user name with non-ASCII characters no longer stops the mod, and
  nothing in the mod can stop the game's load.
- Cloned vehicles really join their line; builds right after loading replicate;
  an out-of-order action no longer lands a step late; a missing command that is
  already due holds the game at once.
- Level-crossing construction, demolition and rail bridge companions fixed;
  big-map stutter fixes with step-locked split heals; exact line colours.
- Brighter, smoother player cursors; host speed buttons 1 to 4.5 in halves plus
  -0.25 / +0.25 with a "speed" toggle; the in-game chat input opens only when
  asked for; the host's stats row shows its distance from you in steps.
- Experimental previews for new stations, depots and other construction
  buildings; multiplayer-side compatibility for Natural Town Growth.

The fork's own changes are unchanged: Resync section in the Multiplayer window,
native recovery panel without a status button, repaired desync log prompt.

## Merge notes

- Three conflicts, resolved by keeping both sides: the version, the Multiplayer
  window (Resync section plus the host-speed toggle) and the lobby's run_client
  signature (recovery runtime plus punch queue).
- Wire protocol stays 4; the lobby version is 0.4.27.
- Upstream now packages `plugins/tpf2_previews.dll` unconditionally, so the
  fork's optional `PreviewPlugin.wxs` fragment and its `PreviewDll` define were
  removed; the first 0.4.27 CI build failed on that duplicate.

## Validation

- luacheck 25/25. Fork tests (Lua producer, barrier, snapshot, runtime, UDP
  lobby recovery, desync report) and upstream tests (previews, preview
  performance, heal step lock, line create, crossing replay, clone buy, big-map
  hash, land replays, road under bridge, rendezvous, delay hold) pass on the
  merged tree. `deterministic_script_test.py` needs the Natural Town Growth
  workshop files and fails identically on the upstream release without them.
- Menu, slice, plugin host, preview and bridge DLLs build with MSVC.
- No game test of the merged package yet. The resync live tests were made on
  0.4.26 sources; upstream's own game testing covered its 0.4.22 sources. The
  combination is verified only by the tests above.

## Known limitations

- Automatic resync still supports two players in a player-hosted lobby on the
  supported Windows game build 35924.
- While the world is held, the Multiplayer window cannot be clicked; Retry and
  Cancel are only in the native panel.
- The historical Vulkan/Device-lost crash remains an open limitation.

Previous releases remain available.
