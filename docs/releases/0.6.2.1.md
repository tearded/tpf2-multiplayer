# 0.6.2.1 — construction parameter transport fix

Construction parameter strings and table keys now preserve embedded newlines
without splitting multiplayer command records. This fixes a reproduced transport
bug that can cause station module edits/removals to be skipped on another player
with `unfinished string near <eof>` and leave different station layouts.

## Validation and known limitations

The new regression failed before the fix and passes after it. Automated checks
cover all 256 byte values, multiline keys and metadata, the actual line receiver,
duplicate commands, retained history, and station removal diffs on origin and peer
with a mocked engine. Parameter depth/cycle checks and Lua validation also pass.
The release workflow runs the full build suite, validates the MSI, and checks its
uploaded download and hash before publication.

This release is for a shared game test. The exact original malformed payload was
not retained in the reported desync logs; confirmation of that specific station
case in the game is pending. Separate money/refund discrepancies are not claimed
fixed. Existing divergent worlds require resynchronization before testing.
The 0.6.2 feature test limitations remain, including AutoSig2 replace/remove modes.

All players must update to **0.6.2.1** through the existing launcher:
**Mein Fork → Aktualisieren und spielen**, after closing their games normally.
Test station module removal and rebuilding from a synchronized world, then check
that both layouts, balances and subsequent SYNC results agree.
