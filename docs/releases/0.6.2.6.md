# 0.6.2.6 — vehicle names travel with the purchase

New vehicles now carry the same name on every instance. The engine names a
bought vehicle locally, in the game's own language and with its own per-type
counter ("Train 7" on an English game, "Zug 7" on a German one, or a different
number after a failed purchase on one side). Nothing on the wire carried that
name, and the native train reservation order ranks trains by name, so an
English and a German game let the same trains through a junction in different
orders. This showed up as "DESYNC (train names)" a stamp after every new train
left its depot, with identical geometry throughout (logs of 2026-09-18).

The originating instance now ships the name the engine gave its copy as a
VNAME as soon as the purchase key binds, and every peer renames its copy. A
peer whose key is not bound yet retries the rename on the step grid, with the
same budget as the company paint. Clones and company purchases take the same
path. A player's manual rename is unchanged.

## Validation and known limitations

A new Lua 5.2 regression drives the real vehicles.lua through the purchase
bind, the escaped name on the wire (including non-ASCII), the peer's rename,
the retry until the key binds, the retry budget, and the originator skipping
its own copy. Existing vehicle key, clone, depot, line-choice and train-name
lane regressions still pass locally. Different game languages have not yet
been verified in a joint game test with this build; watch the log for
"VNAME: vehicle" after a purchase and for a clean SYNC afterwards.

Vehicles bought before this update keep whatever names they have on each
instance; rename them once on any instance to align them. Refund/balance
discrepancies, the native crash while joining a lobby from an already running
world, and the depot, automatic line-stop selection and audio limitations from
earlier releases remain as before. All participants need this version.

The release workflow runs regressions, builds and validates the complete MSI,
and verifies the uploaded download and SHA-256 before publication.
