# 0.6.2 — lobby save selection and tool compatibility

- The host can select a saved game directly in the lobby before starting.
- Road ownership changes carry the owner through multiplayer replay, including
  switching back to public roads. Existing owners survive splits and bridge replacements.
- AutoSig2 automatic placement plans its follow-up signals after the initial
  signal is replicated, then schedules them through the normal multiplayer queue.

## Validation and known limitations

Feature-specific automated tests cover save selection and start guards, native
ownership decoding, ownership replay across different player IDs, and the installed
AutoSig2 algorithm in both directions. These use simulated engine interfaces.
The actual multiplayer game test is still pending for all three changes, including
AutoSig2's resource-wrapper registration. Its replace/remove modes are not covered
by this compatibility change. All peers must use the same version.

The local full build and regression suite passed. Its MSI was extracted and all
73 packaged files were verified against the build. The release workflow rebuilds
and validates the tagged source, then checks the uploaded MSI's download and hash
before publishing it to the launcher's Mein Fork feed.

Update through the existing launcher: **Mein Fork → Aktualisieren und spielen**.
Close all running games normally before activating the update.
